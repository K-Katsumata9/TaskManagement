# データベース設計

[← 要件定義書に戻る](requirements.md)

## list（リスト）
| カラム名 | 型 | 説明 |
|---|---|---|
| id | 数値 | 主キー |
| title | 文字列 | リスト名 |
| position | 数値 | 表示順 |

## card（カード）
| カラム名 | 型 | 説明 |
|---|---|---|
| id | 数値 | 主キー |
| list_id | 数値 | 所属するリストのid |
| title | 文字列 | カードのタイトル |
| description | 文字列（任意） | カードの詳細（タイトルだけでは書ききれない補足内容）。未設定可 |
| due_date | 日付（任意） | カードの期限。カレンダー形式のモーダルUIから入力する。未設定可 |
| position | 数値 | リスト内の表示順（ドラッグ&ドロップやボタンでの並び替えを反映） |
| priority | 文字列 | 優先順位（高／中／低） |
| created_at | 日時 | 作成日時 |
