# データベース設計

[← 要件定義書に戻る](requirements.md)

## list（リスト）
| カラム名 | 型 | 説明 |
|---|---|---|
| id | 数値 | 主キー |
| title | 文字列 | リスト名 |
| position | 数値 | 表示順 |

## card（カード）
| カラム名 | 型 | 説明 |
|---|---|---|
| id | 数値 | 主キー |
| list_id | 数値 | 所属するリストのid |
| title | 文字列 | カードのタイトル |
| position | 数値 | リスト内の表示順 |
