# Trello風タスク管理アプリ 要件定義書

## 1. 概要
Trelloのような、リスト（列）とカードでタスクを管理できるシンプルなWebアプリを作成する。
学習目的のため、機能は最小限に絞る。

## 2. 目的
- タスクを「未着手」「作業中」「完了」のような列で視覚的に管理できるようにする
- カードのドラッグ&ドロップで進捗を移動できるようにする

## 3. 利用者
- 自分一人のみ（ログイン機能なし）

## 4. 技術構成
| 項目 | 使用技術 |
|---|---|
| フロントエンド | React |
| バックエンド | Java（Spring Boot） |
| データベース | PostgreSQL |

## 5. 機能要件（最小構成）

### 5.1 リスト（列）
- リストを作成できる（例：未着手／作業中／完了）
- リストを削除できる

### 5.2 カード（タスク）
- カードを作成できる（タイトルのみ）
- カードの内容を編集できる
- カードを削除できる
- カードをドラッグ&ドロップで別のリストに移動できる

## 6. 非機能要件
- ログイン機能は実装しない（利用者が自分一人のため）
- レスポンシブ対応は必須としない（PCブラウザでの表示を優先）

## 7. 画面構成（案）
- ボード画面（1画面のみ）
  - 複数のリストを横並びで表示
  - 各リストの中にカードを縦に並べて表示
  - 「＋リストを追加」「＋カードを追加」ボタン

## 8. データ構造（案）

### list（リスト）
| カラム名 | 型 | 説明 |
|---|---|---|
| id | 数値 | 主キー |
| title | 文字列 | リスト名 |
| position | 数値 | 表示順 |

### card（カード）
| カラム名 | 型 | 説明 |
|---|---|---|
| id | 数値 | 主キー |
| list_id | 数値 | 所属するリストのid |
| title | 文字列 | カードのタイトル |
| position | 数値 | リスト内の表示順 |

## 9. 対象外（今回は作らない機能）
- ユーザー登録・ログイン
- カードへのラベル・期限・添付ファイル
- 複数ボードの管理
- コメント機能
