# 技術スタック

[← 要件定義書に戻る](requirements.md)

## 1. 基本構成

| 項目 | 使用技術 | バージョン | 補足（一般的な説明） |
|---|---|---|---|
| フロントエンド | React（TypeScript） | React 19.2.8 | 画面（ブラウザ上の見た目・操作部分）を作るための技術。型を用いて実装ミスを防ぎやすいTypeScriptを採用 |
| バックエンド | Java（Spring Boot） | Java 25（LTS）/ Spring Boot 4.0.3 | データの登録・更新・削除などの処理を行うサーバー側の仕組み |
| データベース | PostgreSQL | PostgreSQL 17（Dockerイメージ`postgres:17`、実機は17.11） | タスクやリストの情報を保存しておく仕組み |

※ いずれも実績が豊富で長期的な保守がしやすい技術を採用している。

## 2. フロントエンド周辺技術

| 項目 | 使用技術 | バージョン | 補足 |
|---|---|---|---|
| 言語 | TypeScript | 6.0.2 | JavaScriptに型を付けた言語。実装ミスの早期発見や、コードの読みやすさ向上のために採用 |
| パッケージ管理 | npm | 10.9.2（Node.js 23.11.0） | ライブラリのインストール・バージョン管理を行うためのツール |
| ビルドツール | Vite | 8.2.0 | React（Next.jsは使用しない）のSPA構成を、高速に開発・ビルドするためのツール |
| スタイリング | Tailwind CSS | 4.3.3 | あらかじめ用意された小さなクラスを組み合わせて見た目を作るCSSライブラリ |
| ドラッグ&ドロップ | dnd kit（npmパッケージ） | 未導入（ドラッグ&ドロップ機能の実装時に追加予定） | カードの並び替え（ドラッグ&ドロップ）を実装するためのReact向けライブラリ |

## 3. バックエンド周辺技術

| 項目 | 使用技術 | バージョン | 補足 |
|---|---|---|---|
| ビルドツール | Gradle | 9.5.1（Wrapper同梱） | Javaプロジェクトのビルド・依存関係管理を行うツール |
| データアクセス | Spring Data JPA | Spring Boot 4.0.3に同梱のバージョン | Javaのオブジェクトとデータベースのテーブルを対応付け、SQLを直接書かずにデータ操作を行う仕組み |

※ 上記バージョンは2026年8月時点の開発環境での実績値。今後のアップデートにより変わる可能性がある。

## 4. 構成イメージ

```
[ブラウザ]
   ↓ HTTP（API通信）
[React（TypeScript / Vite / npm）] ──┐
[Tailwind CSS］                     │  フロントエンド
[dnd kit]                           │  （画面表示・ドラッグ&ドロップ操作）
   ↓
[Spring Boot（Gradle）]
   ↓ Spring Data JPA
[PostgreSQL]
```
